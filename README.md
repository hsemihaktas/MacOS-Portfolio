## 📖 Genel Bakış

**macOS Portfolio**, macOS ekosisteminin (Sonoma & Sequoia) görsel dilini, pencerelerini, dock yapısını ve sistem işlevlerini web tarayıcısına taşıyan deneysel ve kullanıcı odaklı bir portfolyo web uygulamasıdır.

Ziyaretçiler sadece projeleri incelemekle kalmaz; tıpkı gerçek bir Mac kullanır gibi pencereleri taşıyabilir, boyutlandırabilir, Spotlight ile sistem içi arama yapabilir, Denetim Merkezi üzerinden temayı ve parlaklığı kontrol edebilir ya da dahili Mail uygulaması üzerinden doğrudan e-posta gönderebilirler.

---

## ✨ Öne Çıkan Özellikler

### 🖥️ Otantik macOS Masaüstü Deneyimi

- **Dinamik Menü Çubuğu (Menu Bar):** Gerçek zamanlı saat, pil durumu, Wi-Fi göstergesi, Spotlight arama ve Denetim Merkezi kısayolları.
- **Etkileşimli Dock:** Fare üzerine geldiğinde akıcı büyütme efekti (magnification), açık uygulama göstergeleri ve doğrudan sosyal profil kısayolları.
- **Tam Fonksiyonlu Pencere Yönetimi (Window Manager):**
  - Sürükle & bırak ile serbest konumlandırma
  - Kenarlardan ve köşelerden serbest boyutlandırma (Resize)
  - macOS trafik ışıkları kontrolleri (Kapat, Simge Durumuna Küçült, Tam Ekran / Büyüt)
  - Odaklanan pencereyi öne alma (Z-Index katman yönetimi)
- **Glassmorphism & Canlı Bulanıklık:** Apple'ın tasarım diliyle uyumlu şeffaf cam efektleri ve modern gölgeler.

### 🔍 Spotlight Arama (`Cmd + Space` / Arama Butonu)

- Projeler, teknolojiler ve sistem uygulamaları arasında anında arama
- Arama sonuçlarından tek tıkla ilgili projeyi veya filtreli proje listesini açabilme

### 🎛️ Denetim Merkezi & Sistem Ayarları

- **Dark / Light Mode:** Tüm sistem ve pencerelerle senkronize çalışan açık/koyu tema geçişi
- **Parlaklık Kontrolü:** Ekran parlaklık seviyesini ayarlayabilen dinamik filtre
- **Wi-Fi Simülasyonu:** Bağlantıyı kapatma/açma ve çevrimdışı durum uyarıları
- **Çoklu Dil Desteği:** Türkçe ve İngilizce tam yerelleştirme (i18n)

### 📱 Kusursuz Mobil & Tablet Uyumluluğu

- Mobil cihazlarda masaüstü karmaşasını önlemek için otomatik olarak **iOS tarzı** tam ekran pencere akışına ve mobil dock/navigation yapısına geçiş.
- Mobil cihazlar için özelleştirilmiş dokunmatik Denetim Merkezi.

- **Çekirdek:** [Next.js 16](https://nextjs.org/) (App Router), [React 19](https://react.dev/), [TypeScript](https://www.typescriptlang.org/)

- **Analitik & Metrikler:** [Firebase Analytics](https://firebase.google.com/)
- **Dağıtım (Deployment):** [Vercel](https://vercel.com/)

## 🚀 Kurulum ve Başlangıç

Projeyi yerel makinenizde çalıştırmak için aşağıdaki adımları takip edebilirsiniz:

### 1. Depoyu Klonlayın

```bash
git clone https://github.com/hsemihaktas/MacOS-Portfolio.git
cd MacOS-Portfolio
```

### 2. Bağımlılıkları Yükleyin

```bash
npm install
# veya
yarn install
# veya
pnpm install
```

### 3. Ortam Değişkenlerini Tanımlayın

Kök dizinde bir `.env.local` dosyası oluşturun ve gerekli anahtarları ekleyin:

```env
# Resend API (İletişim formu için)
RESEND_API_KEY=re_your_resend_api_key_here

# Firebase Analytics (Opsiyonel / Analitik takibi için)
NEXT_PUBLIC_FIREBASE_API_KEY=your_firebase_api_key
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your_project.firebaseapp.com
NEXT_PUBLIC_FIREBASE_PROJECT_ID=your_project_id
NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=your_project.appspot.com
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=your_messaging_sender_id
NEXT_PUBLIC_FIREBASE_APP_ID=your_app_id
NEXT_PUBLIC_FIREBASE_MEASUREMENT_ID=your_measurement_id
```

### 4. Geliştirme Sunucusunu Başlatın

```bash
npm run dev
```

Tarayıcınızda [http://localhost:3000](http://localhost:3000) adresine giderek projeyi görüntüleyin.
